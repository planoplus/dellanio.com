01

Dar direção. Abrir espaço.

Times precisam de contexto para decidir e de confiança para crescer. Meu trabalho começa por alinhar objetivos, desenvolver pessoas e construir uma rotina de colaboração.

  • Gestão de equipes multidisciplinares
  • Conversas 1:1, mentoria e avaliações 360°
  • Objetivos compartilhados e cultura ágil

Scrum / Kanban / OKRs / Jira

02

Decisões que sustentam o próximo passo.

Arquitetura conecta o que o negócio precisa hoje ao que o sistema deve suportar amanhã. Atuo na evolução de plataformas, definição de padrões e integração entre sistemas críticos.

  • Arquitetura corporativa e microsserviços
  • APIs, eventos e mensageria
  • Segurança e evolução de plataformas

Java / Spring Boot / Kafka / RabbitMQ / Keycloak

03

Fazer chegar. Continuar evoluindo.

Uma boa decisão precisa funcionar em produção. Conecto cloud, automação e critérios de qualidade para dar consistência às entregas, explorando também aplicações práticas de IA.

  • CI/CD e testes automatizados
  • Workloads críticos em cloud e on-premise
  • IA generativa em fluxos corporativos

AWS / OCI / ArgoCD / GitLab / LangChain / Bedrock
